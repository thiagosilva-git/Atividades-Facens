Site de Alistamento – Redesign (Deploy)

Projeto de redesign da plataforma de Alistamento Militar Brasileiro, com foco em usabilidade, acessibilidade e performance.
Este repositório contém a versão de deploy do site (arquivos prontos para publicação).

Objetivo: entregar uma interface mais moderna, clara e eficiente para o cidadão concluir o alistamento com menos atrito e maior transparência no fluxo.

✨ Destaques

UX/UI aprimorados: layout limpo, hierarquia visual clara e microcopy orientada à ação.

Acessibilidade: contraste adequado, navegação por teclado, rótulos de formulário e ARIA.

Responsivo: funcionando bem em celulares, tablets e desktops.

Performance: assets otimizados e carregamento rápido.


🧱 Tecnologias

HTML5, CSS3, JavaScript puro.
